### How I work with AI

I don't trust AI to write good code, so I built a loop that doesn't need trust. A planner agent turns each decision into a question I answer. Claude Code writes against strict rules and the Figma design. Hooks check every edit, a test planner proposes edge cases for Jest and Cypress, and four AI reviewers check the code in parallel while a fifth tries to prove them wrong. The same rules run again on commit and in CI.
